# Curso-EBAC-Ciclo-TDD
Diagrama explicativo sobre o ciclo Red, Green, Refactor do TDD

Diagrama feito no draw.io para fixar o conceito do Ciclo Red, Green, Refactor do TDD (Test-Driven Development).
O conceito de TDD fala sobre a criação/elaboração de testes, antes da elaboração do código da aplicação. É um paradigma que reforça a importância do conhecimento e entendimento das regras
de negócio antes da construção da aplicação, força o desenvolvedor a pensar em como o código deve se comportar.

O paradigma TDD é baseado no Ciclo Red, Green, Refactor:
Red - Escrever um teste e vê-lo falhar. Por exemplo: é a elaboração de uma função de teste unitário, para testar o funcionamento de uma função da aplicação que ainda não existe.
Green - Escrever o código mínimo para passar no teste.
Refactor - Melhorar o código, se necessário, mantendo todos os testes passando.

Benefícios do TDD:
- Confiança no código: cada funcionalidade é testada desde o início;
- Design melhor: obriga a pensar na interface, antes da implementação;
- Documentação viva: os testes mostram como o código deve funcionar;
- Refatoração segura: mudanças não quebram funcionalidades já validadas
